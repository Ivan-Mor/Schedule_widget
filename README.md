# MalinovkaWidget — виджет расписания транспорта (Минск, Малиновка)

Личный Android-виджет 4×2: минуты до прибытия маршрутов **103, 114с, 150**
в двух направлениях — «Малиновка 7 → метро» и «Ст. метро Малиновка → Малиновка 7».

Полное техническое задание и решения — в [docs/](docs/):
- [docs/decisions.md](docs/decisions.md) — зафиксированные решения;
- [docs/data-sources.md](docs/data-sources.md) — сравнение источников данных
  (Яндекс = live, Btrans = свежее расписание JSON, Минсктранс = резерв).

## Сборка

1. Android Studio (или JDK 17+ и Android SDK с платформой 36).
2. Открыть корень проекта, дождаться Gradle Sync (wrapper уже в репозитории).
3. `./gradlew assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`.

Стек: Kotlin 2.4, Jetpack Glance (виджет), Compose Material3 (настройки),
OkHttp, Jsoup, kotlinx.serialization, DataStore, Room. minSdk = targetSdk = 36.

## Как это работает

Цепочка источников (сбой звена не ломает виджет — берётся следующее):

1. **Яндекс Карты** — live-прогноз, вшитый в HTML страницы остановки;
2. **btrans.by `/schedule-data`** — свежее плановое расписание в JSON;
3. **Room-кэш** последнего удачного обновления (10 минут);
4. **Зашитый дамп расписания** (`app/src/main/assets/schedule.json`,
   генерируется `research/generate_schedule_dump.py`).

Обновление виджета: кнопка «⟳», включение экрана (порог свежести 45 с,
без лишних запросов), после перезагрузки телефона. Тема — по времени:
тёмная 18:00–06:00, перерисовка на границе — дешёвым будильником.

Кнопка «Выхожу» запускает мониторинг на 15 минут (направление берётся
из настроек): опрос каждые 30 секунд, по одному уведомлению на маршрут,
когда подача попадает в порог «пора» (настраивается). Останов — таймер,
«все маршруты подали» или кнопка в уведомлении.

## После установки на телефон (HyperOS / Redmi)

1. Запустить приложение, выбрать направление «Выхожу», маршруты и порог.
2. Разрешить уведомления (кнопка на экране настроек).
3. Настройки → Приложения → «Малиновка Транспорт» → Батарея → **«Без ограничений»**
   и включить **автозапуск** — иначе мониторинг «Выхожу» будет прибит системой.
4. Добавить виджет 4×2 долгим тапом по рабочему столу.

## Ограничения MVP (осознанные)

- Обновление «при включении экрана» работает, пока жив процесс приложения
  (manifest-приёмник `ACTION_SCREEN_ON` запрещён с API 26). Первое открытие
  приложения после установки/перезагрузки «оживляет» его; кнопка «⟳»
  обновляет всегда.
- Яндекс — внутренний формат страницы: если изменится вёрстка, парсер упадёт,
  виджет перейдёт на расписание (это и есть задуманный фолбэк).
- Соответствие платформ-направлений у метро стоит проверить на месте;
  при ошибке меняется одна строка в `Stops` (Model.kt).
- Расписание в дампе — «будни/выходные», без праздников.

## Обновление зашитого расписания

```bash
python3 research/generate_schedule_dump.py   # перезапишет assets/schedule.json
```
Затем пересобрать APK (импорт в Room выполняется один раз при первом запуске
после установки новой версии — флаг `schedule_imported_v1`; при разработке
можно очистить данные приложения).
